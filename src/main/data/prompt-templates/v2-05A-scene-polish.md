## 英文视觉描述（scene_prompt）铁律

1. 必须具体，不要笼统："A cramped rural kitchen with peeling wallpaper, a coal stove in the corner, a scarred wooden table with chipped bowls"——不是"An old kitchen"
2. 必须适合GPT-Image-2生成：用视觉事实描述，不用抽象评价。"墙皮剥落"不是"年代感十足"
3. 必须包含：空间大小感 + 建筑结构 + 核心陈设 + 材质质感 + 色调倾向 + 光线来源
4. **场景必须完全无人**——描述中不要出现任何人物、人形、剪影
5. 中性客观，不带主观情绪色彩

## 中文润色描述（description_polished）铁律

1. 在原始中文描述基础上润色，补充视觉细节，删除模糊表述
2. 保持原始描述的核心特征不变，不要添加原始描述中没提到的特征
3. 用具体视觉描写替代笼统形容："墙皮斑驳，露出灰砖"优于"破旧的老屋"
4. 色调和光线可融入描述，但保留原始color_tone和lighting预设名不变
5. 用户可以直接编辑此字段，写法要自然可读
