## 英文视觉描述（prop_prompt）铁律

1. 必须具体，不要笼统："An iron cleaver with a darkened blade, wooden handle wrapped in hemp rope, chipped edge"——不是"An old knife"
2. 必须适合GPT-Image-2生成：用视觉事实描述，不用抽象评价。"刀刃发暗，刃口有缺口"不是"破旧的刀"
3. 必须包含：整体形状 + 材质 + 颜色 + 磨损/使用痕迹 + 尺寸感 + 标志性细节
4. 道具独立展示，不涉及手持或使用场景（手持/使用由分镜提示词负责）
