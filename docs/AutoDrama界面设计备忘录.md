## 二、项目总览页（Editor.vue - overview）

### 2.1 常态展示
- 页面内容居中显示
- 画面风格选择：13种预设网格 + 自定义风格卡片按钮（跟预设卡片同样大小，放在一起，点击打开自定义风格弹窗）
- 画面比例选择（16:9横屏 / 9:16竖屏 / 1:1方形）
- 统计卡片：角色/场景/道具/剧集/分镜数量展示（纯展示，无交互功能，避免页面太空）
- 剧本解析和追加解析：做成卡片样式，跟风格卡片同样大小
  - 剧本解析 = 完整解析（清空分镜重来），点击打开解析弹窗
  - 追加解析 = 保留已有分镜，添加新分镜；角色/场景/道具按"只创建不覆盖"处理，点击打开追加解析弹窗

### 2.2 AI解析弹窗（点击"AI解析剧本"弹出）
1. 顶部标题：导入剧本 + 关闭按钮
2. Tab切换：AI生成 / 手动切分（MVP1先做AI生成，手动切分占位）
3. 剧本输入区：粘贴文本，显示字数统计，建议500字以上
4. 画面风格选择：13种预设网格 + 自定义
5. 画面比例选择：16:9横屏 / 9:16竖屏 / 1:1方形
6. 提示词模板：下拉选择预设（标准分镜/精细镜头拆分/纯分镜/短视频制作），可展开预览模板内容，"管理提示词模板"入口
7. 模型选择：下拉选当前配置的模型
8. 底部按钮：暂时跳过 + 一键生成分镜

## 三、角色管理页

> 注意：项目总览页的角色/场景/道具独立管理页取消，统一在剧集结构页右侧面板管理

### 3.1 列表视图
- 角色方格网格布局，每个角色是一个方格按钮
- 方格上方：角色图片缩略图（没生成图片前显示角色名字居中）
- 方格下方：角色名字
- 每个缩略图增加删除功能（红叉角标，删除AI生成但不需要的角色）
- 鼠标悬停（延迟300-500ms）：弹出放大预览 + 角色信息（名称、描述、提示词）

### 3.2 角色详情（点击方格按钮进入）
> 从剧集结构页出场人物点击进详情，与从右侧面板缩略图点进详情，是同一个视图，各回各家返回
1. 展示窗口：大图预览区，右侧是"皮肤"缩略图列（默认+可添加+皮肤），MVP1没图片先占位
   - 点击展示窗口可全屏看大图
2. 角色名称文本框：可编辑，改名字全局联动（store+数据库+所有引用处）
3. 名称右边：选择图片按钮
   - 上传本地（MVP1实现）
   - 资产库导入（MVP1占位）
4. 角色描述文本框（较大）：解析出的角色描述，可编辑改写，改完全局联动
5. ~~自动改写/手动改写按钮~~ → 不要
6. 拉开距离，生图控制栏：
   - 小齿轮 → 弹出生图模型选择面板（多种模型可选，显示渠道/参数配置，去掉消耗那行）
   - 生成张数选择：-/+ 按钮调节 + 支持直接输入数字
   - AI生图执行按钮
   - 生图提示词逻辑：用户只看到角色描述字段（可编辑），风格提示词/项目模板提示词用户不可见，生图时后台自动拼接（角色描述 + 风格提示词）调用API
7. 历史记录：底部记录所有生成过的图，用户可选择哪张好选哪张

## 六、剧集结构页

### 6.1 整体布局
- 横向列表，一行一分镜，列头固定
- 固定列宽，内容超长时增加行高（自动换行/多行缩略图）
- 所有可生成的列，列头放批量操作按钮

### 6.2 列头
双行设计：上行列名称，下行批量按钮（只有可生成的列有批量按钮，其他空着）

| 序号 | 剧本 | 出场人物 | 场景 | 道具 | 配音 | 首帧 | 首帧提示词 | 尾帧 | 尾帧提示词 | 视频 | 操作 |
|------|------|----------|------|------|------|------|------------|------|------------|------|------|
|      |      | [批量生成] | [批量生成] | [批量生成] |      | [批量生成] |      | [批量生成] |      | [批量生成] |      |

### 6.3 各列设计

#### 序号列
- 分镜编号
- 每行序号前有复选框，支持单选
- 列头有全选框，点击全选/取消全选整列

#### 剧本列（视频提示词）
- 适当缩小列宽，长文本截断+换行
- 双击进入编辑，可改写分镜描述/提示词
- 下方显示关联标签：解析出的角色名、场景名、道具名以标签形式显示
- 智能关联：编辑时输入未关联的角色/场景/道具名称，自动关联并全局联动
- 高亮显示：提示词中关联成功的角色名字高亮显示（如浅蓝色），位置不变

#### 出场人物列
- 固定列宽，一行3个缩略图，多的话增加行高再加一行
- 缩略图方格：有图显示图，没图灰底占位+名字
- 本质是按钮，点击后右侧面板切换显示角色详情（大图+皮肤+名称+描述+提示词+生图控制+历史记录），方便就地修改
- 列头有[批量生成]按钮：批量生成角色定妆照

#### 场景列
- 同出场人物列逻辑：固定列宽，一行3个缩略图
- 点击切换右侧显示场景详情
- 列头有[批量生成]按钮：批量生成场景定妆照

#### 道具列
- 同出场人物列逻辑
- 点击切换右侧显示道具详情
- 列头有[批量生成]按钮：批量生成道具定妆照

#### 配音列
- 配音按钮，点击后右侧面板显示"功能开发中"（与其他列的交互逻辑一致：右侧面板是上下文详情区）
- MVP3实现：选音色(TTS模型) + 配置对白 + 生成音频 + 对时间轴

#### 首帧提示词列
- 显示AI自动生成的首帧提示词文本（由分镜提示词模板决定是否输出）
- 双击进入编辑，可改写，改写后生图时用改写后的提示词
- 下方显示关联的角色/场景/道具标签（同剧本列逻辑）
- 编辑时输入未关联的角色/场景/道具名称，自动关联并全局联动
- 提示词中关联成功的名字高亮显示
- 选择"标准分镜"等模板时有内容，选择"纯分镜"等模板时此列为空

#### 尾帧提示词列
- 同首帧提示词列逻辑
- 双击进入编辑，可改写
- 下方显示关联标签，智能关联+高亮，同剧本列
- 选择不需要尾帧的模板时此列为空

#### 首帧列
- 首帧图片预览（没图时灰底占位）
- 点击首帧图片/占位，右侧面板显示首帧详情：
  - 首帧图片预览（大图，可全屏）
  - 首帧提示词（可编辑）
  - 生图控制栏（模型选择+张数+生图按钮，同角色的生图控制）
  - 历史记录（生成过的图可选）
- 列头有[批量生成]按钮：批量生成所有分镜首帧图

#### 尾帧列
- 尾帧图片预览（没图时灰底占位）
- 点击尾帧图片/占位，右侧面板显示尾帧详情：
  - 尾帧图片预览（大图，可全屏）
  - 尾帧提示词（可编辑）
  - 生图控制栏（模型选择+张数+生图按钮，同角色的生图控制）
  - 历史记录（生成过的图可选）
- 列头有[批量生成]按钮：批量生成所有分镜尾帧图

#### 视频列
- 视频缩略图预览，可点击
- 每次新生成的视频有角标"new"，点击后消失
- 点击后右侧面板显示视频详情：
  - 视频展示窗口：大图/视频播放，点击可全屏播放（底部播放控制栏：播放/进度条/音量等）
  - 中间部分：模型选择（齿轮）+ 数量增减（- N +）+ AI生视频按钮（同角色生图控制栏风格）
  - 备选素材区：标题"备选素材(X/Y)" + "全部移除"按钮
    - 每个素材缩略图，左下标注模型名，右下标注日期
    - 鼠标悬停显示两个按钮：✓选中 / 🗑删除
    - 点击✓选中：该视频出现在视频列缩略图中，同时上方展示窗口展示该视频，导出时以视频列选中的为准
    - 点击🗑删除：删除该素材
  - 下方历史记录：与角色相同，记录所有生成过的视频
- 列头有[批量生成]按钮：批量生成所有分镜视频

#### 操作列
- 上下移动（调整分镜顺序）
- 删除

### 6.5 顶部工具栏
- **左侧**：项目名称 + 风格标签 + 年代标签 + 模型配置按钮
- **中间**：编辑器按钮 + 画布按钮（使用频率最高，放在最中间，按钮样式与其他做区分，更突出）
- **右侧**：生成记录按钮 + 撤销/重做 + 导出按钮 + 设置

#### 项目名称
- 双击可修改
- 导出时用作文件命名

#### 风格标签
- 点击弹出风格选择面板：
  - 左侧：风格选择网格（4列多行），每个风格卡片有预览图+名称，底部有"+ 自定义风格"按钮
  - 右侧：选中风格的示例展示（人物多角度+场景示例），让用户直观看到效果
- 官方预设风格：预览图和示例图打包在安装包中，不可编辑不可删除
- 选择后改变后台隐藏的风格提示词，全局生效
- **自定义风格弹窗**（点击"+ 自定义风格"打开）：
  - 左侧：参考图上传区（可上传多张图片），上方有"启用参考"开关——控制这些参考图是否在生图时传给API
  - 右侧：风格名称输入框 + 提示词输入框
  - 底部：取消 + 添加按钮
  - 保存后出现在风格选择网格中，可编辑可删除

#### 年代标签
- 点击可设置年代（古代/现代/未来等）
- 设置后自动注入到所有提示词中，作为全局时空背景关键词

#### 模型配置按钮
- 点击弹出模型配置页面（不是跳转Settings.vue，是独立弹窗）
- 顶部：导入配置按钮 + 导出配置按钮（整个模型配置的导入导出，包括所有用途的模型选择+渠道+提示词模板等，方便备份和共享）+ 导出时支持加密 + 新手/专业模式切换
- **导入/导出采用发包模式**：导出为JSON文件（图片转base64内嵌），导入时选择文件解析写入数据库，纯本地文件交换，不自动不联网
- 同样机制适用于风格包和模板包的导入导出
- 按用途分组独立配置：
  1. **语言模型**：推理模型选择 + 渠道（显示成功率+平均耗时）+ 消耗 + 功能开关（脚本提示词/解析提示词）
  2. **单分镜剧本改写**：同上
  3. **角色生图模型**：生图模型选择 + 渠道 + 分辨率 + 消耗 + 功能开关
  4. **场景生图模型**：同上
  5. **道具生图模型**：同上
  6. **分镜图生图模型**：模型 + 渠道 + 分辨率 + 消耗 + 功能开关 + 参考图范围（人物/场景/道具勾选）
  7. **视频生成模型**：同上结构
- 每个用途独立配置模型和渠道，不同用途可以用不同模型

> 【质疑】此节描述的模型配置弹窗功能非常完整（导入导出/新手专业模式/7用途独立配置/消耗统计/功能开关），但MVP1+MVP2批次1实际仅实现了基础Tab切换+模型选择+模板列表占位+分组过滤。建议将完整功能拆分为M2-10~M2-12逐步实现，避免单一步骤过大。

##### 模板系统（每个用途内部独立）
- 左侧分两Tab：
  - "指令模板"：官方预设模板列表，每个模板有名称+说明
  - "我的指令"：用户自定义模板列表
- 右侧编辑区：
  - 插入变量栏：输入内容、当前剧本、其他要求、所有角色名、所有场景名、所有道具名、使用角色名、使用场景名、使用道具名等按钮，点击插入变量到指令中
  - 指令编辑文本框：可自定义提示词内容，用变量做模板化
  - **新建模板时的格式提示**：类似扣子智能体System Prompt的占位提示，引导用户按格式写提示词
  - **AI改写按钮**：一键AI优化/改写当前提示词内容
- 底部按钮：取消 / 另存（保存为自定义模板，出现在"我的指令"列表）/ 保存（保存当前修改）
- 与解析弹窗的提示词模板下拉是同一套体系——解析弹窗是快捷入口，模型配置是完整编辑

#### 生成记录按钮
- 点击弹出历史记录窗口
- 三个Tab：视频 / 图片 / 其他
- 表格列：编号 | 所属分镜/素材 | 类型 | 模型 | 渠道 | 创建时间 | 等待时间 | 状态 | 操作
- 状态：✅已完成 / ❌失败 / 进行中
- 操作：重新下发 / 重试 / 查看详情
- 实时动态任务队列，所有后台生成任务都在这里追踪
- 仅显示最近7天的历史记录

#### 撤销/重做
- 操作历史回退和前进
- > **MVP1占位按钮，MVP2实现**：顶部工具栏保留撤销/重做按钮，MVP1阶段按钮存在但功能为空，MVP2接入操作历史栈后生效

#### 导出按钮
- 下拉框，4个选项：视频导出 / 场景导出 / 角色导出 / 道具导出
- **视频导出**：以序号列勾选为依据，导出选中分镜的视频列中选中的视频，支持批量导出
- **角色/场景/道具导出**：切换到对应管理页后，卡片缩略图右下角显示勾选框，勾选后可批量导出图片
- 导出命名规则：序号_项目名_时间（暂定）

#### 设置
- 点击弹出设置页面
- 左侧导航：
  1. 账号与授权（MVP2占位：登录/注册弹窗 + 授权码输入 + 当前授权状态显示，字段和后端逻辑后续接入）
  2. API供应商 & 插件
  3. 模型路由 & 默认
  4. 提示词模板
  5. ComfyUI服务器
  6. ComfyUI工作流
  7. IndexTTS2配音
  8. 火山素材库
  9. 通用设置
  10. 关于
- 右侧内容区：选中左侧导航项后展开对应内容，默认选中第一项"API供应商 & 插件"，没有空白状态
  - API供应商 & 插件：统计标签 + 供应商/插件扩展Tab + 供应商列表（名称/标识/Key数量/模型数量/下载代理开关/刷新/编辑/删除）+ 添加供应商
  - 其他页面：先占位，后续按需实现

### 6.6 右侧面板（剧集结构页专属，非全局）
- **常驻状态**（始终可见）：
  - 顶部小图标：返回/前进/帮助/设置
  - 三个Tab：角色 / 场景 / 道具，右侧有"批量生成"按钮和搜索框
  - 内容区：分"作品中(N/M)"（当前项目的）和"全部可用(N/M)"（在分镜中有高亮关联的=可用，没有任何高亮的=不可用，快速查错）
  - "全部可用"逻辑：角色/场景/道具在至少一个分镜提示词中被高亮关联→可用；零高亮→不可用（孤立资源，可能AI多生成或关联有误）
  - 底部有"创建"按钮+"从其他项目导入"按钮
  - 每个角色/场景/道具是缩略图卡片，点击进入详情
  - 导出时卡片右下角显示勾选框
- **详情状态**：点击缩略图或列表内容时切换显示，点返回回到常驻状态
  - 出场人物/场景/道具方格 → 角色详情/场景详情/道具详情
    - 右侧面板详情中，角色名称和描述均可编辑（名称修改触发全局联动）
    - 提示词模板等不可在右侧面板编辑（需到模型配置弹窗管理）
  - 配音按钮 → "功能开发中"
  - 首帧/尾帧图片 → 首帧/尾帧详情（大图+提示词+生图控制+历史记录）
  - 视频缩略图 → 视频详情（展示窗口+生图控制+备选素材+历史记录）
- 修改后全局联动

## 二十、画布设计（M2-13，2026-05-22确定）

### 整体架构
- **画布 = 编辑器的可视化翻版**：编辑器一行分镜 = 画布一条节点流，编辑器一列 = 画布一个节点，列间数据流转 = 自动连线
- **连线自动生成**：跟着编辑器数据关系走，用户不需要手动连线
- **一个分镜一个空间**：画布上每个分镜是独立的完整区域，包含该分镜所有节点
- 分镜之间无连线，各自独立
- 切换分镜 = 切换画布区域，左侧面板跟着变
- **编辑器与画布是同一套数据两个视角**：编辑器是表格视角，画布是节点流视角

### 节点类型
- **生图节点**（从上到下结构）：
  1. 展开/折叠按钮
  2. 后台提示词缩略展示（不可编辑，暗色显示，如有则显示）
  3. 风格参考图缩略展示（不可编辑，暗色显示，项目风格自动注入，不出现在连线上）
  4. 可编辑提示词区域（点击可弹窗放大编辑）
  5. 模型下拉框（选择生图模型）
  6. 参数按钮行：画面比例（横竖屏选择）+ 分辨率选择
  7. 底部状态栏：动态展示当前工作状态，失败时返回错误信息
  - 节点类型分两类：
    - **资产生图节点**（角色/场景/道具）：输入=风格参考图(预设)+提示词，图生图，输出定妆照/场景图/道具图
    - **帧生图节点**（首帧/尾帧）：输入=角色/场景/道具输出图(连线传入)+风格参考图(预设)+提示词，图生图，输出帧图
- **结果展示节点**：独立节点，显示生成的图片/视频缩略图 + 状态标识，对应编辑器列的缩略图；视频结果支持放大播放
- **视频生成节点**：输入端口（首帧图+尾帧图+角色/场景/道具参考图）+ 提示词/参数 + 输出端口（视频），结构同生图节点

### 节点连线
- **自动生成，跟随编辑器数据关系**：用户在编辑器关联角色/生成图片后，画布自动出现对应节点和连线
- 数据流方向：角色/场景/道具生图 → 结果展示 → 首帧/尾帧生图 → 结果展示 → 视频生成 → 结果展示
- 每个生图/视频节点 → 对应的结果展示节点（自动连线）
- 角色/场景/道具结果 → 首帧生图节点（参考图输入）
- 角色/场景/道具结果 → 视频生成节点（参考图输入）
- 首帧结果 → 视频生成节点
- 尾帧结果 → 视频生成节点（有尾帧时）
- 用户不需要手动拖线连线
- **手动连线也支持**：精修时用户可以手动拖拽端口调整连线（如更换参考图、增删连线），手动修改后连线跟随用户调整

### 节点排列
- 自动排列，从左到右数据流方向

### 节点交互
- 提示词文本区点击 → 弹窗放大编辑
- 双击节点 → 打开详情编辑
- 单击结果节点 → 大图预览
- 其他交互与编辑器对应操作一致

### 画布操作
- 拖拽平移、滚轮缩放
- 适配按钮（当前分镜节点缩放至可视区域）
- 点击空白取消选中

### 底部工具栏（参考Coze工作流画布）
- 画布底部居中显示工具栏
- 功能按钮：添加节点（角色生图/场景生图/道具生图/首帧生图/尾帧生图/视频生成）、缩放控制、适配视图、撤销/重做
- 点击添加节点后选择类型，节点出现在画布上，用户可手动连线

## 二十一、画布精修方案（2026-05-23 讨论，MVP3实施）

### 角色一致性（精修核心能力）
- 生帧图时自动传定妆照作为参考图，GPT-Image-2等支持参考图的模型生效
- 画布精修时可追加额外参考图（多角度、特写等），加强约束
- 参考强度：自动挡默认0.6-0.7，精修模式暴露滑块让用户调
- 模型能力标识：
  - 预置模型：我们标好「角色一致」标签，跟着版本走
  - 自定义模型：添加时有个开关「支持参考图」，默认关，懂的人自己开
  - 不支持参考图的模型：参考图功能不可用

### 构图控制
- 精修时可拖拽/标记角色位置，或画简笔草图指定构图，AI按构图生图（细节MVP3聊）

### 局部重绘
- 圈选局部区域重新生成，不影响其他部分（细节MVP3聊）

### 版本对比
- 同一分镜生了几版，左右对比选片（细节MVP3聊）

### 叙事流（画布核心功能）

#### 画布整体布局
- 进入画布默认显示分镜列表
- **左侧**：分镜列表（竖向大栏，占半屏）
- **右侧**：叙事流列表（竖向大栏，占半屏），默认为空，显示提示文字
- 两栏同时可见，互不影响

#### 叙事流创建入口
- 分镜列表**标头位置**有一张大卡片「叙事流」，提示文字："勾选分镜创建叙事流"
- 未勾选分镜时：卡片为提示状态
- 勾选分镜后：卡片变为可点击的「创建叙事流」按钮

#### 叙事流创建流程
1. 用户在左侧分镜列表中勾选连续的分镜（复选框）
2. 标头卡片「叙事流」变为「创建叙事流」按钮
3. 点击创建 → 右侧叙事流栏出现一张叙事流卡片
4. 叙事流卡片显示：叙事流名称（可编辑）+ 包含的分镜范围（如"#001-#005"）+ 分镜数量

#### 叙事流规则
- 连续分镜区间，不重叠、不交叉
- 视频本身是线性的，不存在同一分镜同时属于两个叙事流的情况
- 用户按需创建，不是默认就有的

#### 叙事流空间
- 点击右侧叙事流卡片 → 进入叙事流空间
- 按分镜顺序展示所有帧（首帧+尾帧交替），检查连贯性
- 叙事流空间内可精修：角色一致性、构图、局部重绘

#### 单分镜精修空间
- 保留不动，不替代
- 用户可以从叙事流空间进入某个分镜的精修空间
- 单分镜精修空间和叙事流空间并列
