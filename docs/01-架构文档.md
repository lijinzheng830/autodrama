## 数据库（16 张表）

### 核心表
- **projects** — 项目（含 style/era/model_config_json）
- **chapters** — 章节/剧集
- **shots** — 分镜（含 description/dialogue/first_frame_prompt/last_frame_prompt）

### 资产表
- **characters** — 角色（name + description 即为提示词主体）
- **scenes** — 场景（同角色结构）
- **props** — 道具

### 关联表
- **shot_characters** — 分镜-角色关联
- **shot_scenes** — 分镜-场景关联
- **shot_props** — 分镜-道具关联

### 历史记录表
- **character_images** — 角色定妆照历史
- **scene_images** — 场景图历史
- **prop_images** — 道具图历史
- **shot_images** — 首帧/尾帧图历史（type: first/last）
- **shot_videos** — 视频历史（has_new_badge 角标）

### 系统表
- **settings** — 键值对设置（provider/model/api_key/providers JSON/model_routes JSON）
- **generation_tasks** — 生成任务队列
- **prompt_templates** — 提示词模板（usage 区分类型，project_id 区分全局/项目级）

## AI 三步管线

```
autoProcess(projectId, script, options)
  │
  ├── 步骤1: callAI(STORYBOARD_PROMPT) → extractJSON → shotsData
  │
  ├── 步骤2: callAI(EXTRACT_PROMPT)    → extractJSON → extractData
  │
  ├── 步骤3: callAI(ASSOCIATE_PROMPT)  → extractJSON → assocData
  │
  └── 步骤4: saveToDatabase(projectId, ...)
       └── 事务写入：chapter → shot → character/scene/prop → 关联
```

**JSON 提取流程** (`extractJSON` + `cleanJSON`):
1. 直接 `JSON.parse` 全文本
2. 提取 ` ```json ``` ` 代码块
3. `cleanJSON` 清理后解析（去尾部逗号、补引号、去前后文字）
4. 提取 `{ }` 或 `[ ]` 区间
5. 失败 → 写入 `ai_response_debug.log` + 抛出错误

**API 调用** (`callAI`):
- 端点: `{baseURL}/chat/completions`
- `response_format: { type: 'json_object' }`
- `temperature: 0.1`
- provider 解析: 支持 `providerKey:modelKey` 格式
- API Key 查找: `api_key_${provider}` → providers JSON fallback
- 硬编码供应商 fallback 只提供 baseURL

## 模型选择降级链

### 生图（`imageGenerator.ts`）
```
L1 传入参数 (model + channel)
  → L2 项目配置 (model_config_json[purpose])
  → L3 全局路由 (model_routes[purpose])
  → L4 自动匹配第一个有 apiKey 的供应商
```

### 齿轮弹窗（前端）
```
L1 sessionOverrides（内存级，重启清空）
  → L2 model_config_json（项目级）
  → L3 model_routes（全局默认）
```

### providerModels 缓存
- Settings 增删改 → `localStorage.providers_dirty = '1'`
- 下次打开齿轮 → 检测 dirty → 清空缓存重载

## IPC 通信

预加载脚本通过 `contextBridge.exposeInMainWorld('api', {...})` 暴露约 50 个方法：

| 类别 | 方法 | 说明 |
|------|------|------|
| 项目 | `createProject/getProjects/getProject/deleteProject/updateProject` | CRUD |
| 资产 | `createCharacter/updateCharacter/deleteCharacter` + scene/prop 同理 | 资产管理 |
| 分镜 | `getShots/getShotsWithAssociations/moveShotUp/Down/deleteShot/updateShot` | 分镜操作 |
| AI | `autoProcess/onAIProgress/generateImage/generateShotImage` | AI 生成 |
| 设置 | `getSetting/setSetting/getProviders/addProvider/updateProvider/deleteProvider` | 配置管理 |
| 导出 | `selectExportDirectory/copyExportFile` | 文件导出 |
| 对话框 | `selectDirectory/selectImage/showSaveDialog/showOpenDialog` | 系统对话框 |

## 关键约定

1. **只创建不覆盖**: AI 解析时已有资产不修改，只建关联
2. **description = 提示词主体**: 角色/场景/道具无独立 prompt 字段
3. **双向同步**: first_frame_prompt 同时用于编辑显示和生图输入
4. **提示词拼接**: finalPrompt = description + stylePrompt + eraPrompt
5. **数据库不 DROP 重建**: 所有变更通过 ALTER TABLE / CREATE TABLE IF NOT EXISTS
6. **项目独立**: 每个项目独立角色/场景/道具，通过 parent_project_id 做续集
7. **ELECTRON_RUN_AS_NODE**: 开发时必须在 package.json dev 脚本中清空此变量
