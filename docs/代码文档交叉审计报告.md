## 二、文档与代码不一致

### D1. 字段映射表 sections 数量有误

**文档** (字段映射表.md): 列出 `section_1_ref_multi_character` 作为独立字段
**代码** (imageGenerator.ts:916): 只用 `section_1_ref_character`，多人场景逻辑直接嵌入 section_5 的 `multi_character_positioning` 变量
**结论**: 文档应删除 `section_1_ref_multi_character` 字段，改为在 section_5 中说明多人逻辑

### D2. 字段映射表 section_5 列出 char_age/char_facial/char_hair 等子字段

**文档**: 列出角色7个子字段（age/facial/hair/outfit/body/marks）
**模板** (v1-07): section_5 只用 `{{char_role}}` 一个占位符，不分拆子字段
**代码** (imageGenerator.ts:905): 只填充 `char_role`，子字段均未实现
**结论**: 文档标注"暂不拆分"[OK]，但模板和文档的 section_5 变量列表不一致。文档应写明当前只支持 `{{char_role}}`

### D3. 管线设计 doc overlay 标注格式含 emoji

**文档** (管线设计.md:163-164):
```
│ 慢推 dolly | 🔉 环境风声  │
│ 🎬 建置时空·角色入场     │
```
**代码** (imageGenerator.ts:776-777): 同样含 emoji
**结论**: 文档和代码都需要改为纯文本
