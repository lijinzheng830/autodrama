## 关键设计决策（固定不变）

1. **文档目录**: `docs/` — 所有设计文档、备忘录、架构说明统一放这里
2. **供应商数据格式**: `models` 字段为对象数组 `{key, name, type, free}`，旧字符串数组兼容（默认type='text'）
3. **模型路由value格式**: `providerKey:modelKey`（如 `image2:gpt-image-2`）
4. **四级降级链**: L1 input参数 > L2 model_config_json > L3 model_routes > L4 自动匹配
5. **app.name保护**: 固定为 `electron-app`，防止userData路径漂移
6. **dev启动方式**: `node launch-dev-split.js`（分开启动Vite+Electron）
7. **数据库时间**: `datetime('now', 'localtime')`（修正8小时时差）
8. **批量生成策略**: 3并发 + 3秒间隔 + 429等5秒重试1次
9. **首帧/尾帧模型配置**: 独立key `first_frame` / `last_frame`，不再用 `shot_image`
