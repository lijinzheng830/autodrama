# 生图模板完整文档

## 一、角色参考图生成

**文件**：`src/main/data/prompt-templates/v1-04-character-image.md`
**DB ID**：`official-v1-character-image`
**用法**：`character_image`

### 模板变量

| 变量 | 代码来源 | 值 |
|------|---------|-----|
| `{{character_description}}` | `characters.description` | 中文字段，LLM 输出的结构化描述 |
| `{{character_appearance_prompt}}` | `characters.description` | 英文字段，同上 |
| `{{style_prompt}}` | `getStylePrompt(style_name, style_prompt)` | 英文画风关键词 |
| `{{style_prompt_zh}}` | `getStylePromptZh(style_name, style_prompt)` | 中文画风关键词 |
| `{{era}}` | `project.era` | 年代标签 |

### 提示词结构（英文版）

```
[MOST IMPORTANT — CHARACTER APPEARANCE]
{{character_appearance_prompt}}  ← characters.description（英文）

[ETHNICITY — CRITICAL]
东亚外貌约束：单眼皮/内双、扁平鼻梁、暖调肤色、深色直发
禁止：欧美特征、深眼窝、高鼻梁、金发、粉白皮肤

[Task]
四面板横排角色参考图，纯白背景

[Composition — 1.6:1:1:1]
面板1（宽1.6）：上半身特写，面正对镜头
面板2（宽1）：全身正面
面板3（宽1）：45°侧身全身
面板4（宽1）：背影全身

[Style] {{style_prompt}}, {{era}}
[Lighting] 专业演播室布光
[Quality] 比例一致、光照统一、间距均匀
```

### 角色描述格式

来自 `v1-12-asset-extract.md` 模板，LLM 按以下格式输出：

**英文**：
```
Role: [身份]. Age: [年龄]. Facial features: [五官+肤色]. Hair: [发色+发型+发长]. Outfit: [上衣+下装+鞋+材质]. Key prop: [核心道具]. Build: [体型]. Distinctive marks: [特征或无].
```

**中文**：
```
身份：[身份]。年龄：[年龄]。五官：[脸型+眉+眼+鼻+唇+气质]，[肤色]。头发：[发色+发型+发长]。服装：[全套描述]。道具：[核心道具]。体型：[身高+体态]。特征：[特殊标记或无]。
```

### API 调用

| 参数 | 值 |
|------|-----|
| 调用函数 | `generateImage(type='character', ...)` |
| 模型 | 从 `model_config_json` 中取 `character_image` 路由 |
| 参考图 | 无（首次生图）；同角色已有图时自动作为参考 |
| 保存 | `character_images` 表，新图 `is_selected=1`，旧图清零 |

## 二、场景参考图生成

**文件**：`src/main/data/prompt-templates/v1-05-scene-image.md`
**DB ID**：`official-v1-scene-image`
**用法**：`scene_image`

### 模板变量

| 变量 | 代码来源 | 值 |
|------|---------|-----|
| `{{scene_description}}` | `scenes.description_zh` | 中文场景描述 |
| `{{scene_prompt}}` | `scenes.description` | 英文场景描述 |
| `{{style_prompt}}` | `getStylePrompt()` | 英文画风 |
| `{{style_prompt_zh}}` | `getStylePromptZh()` | 中文画风 |
| `{{era}}` | `project.era` | 年代 |

### 场景描述格式

来自 `v1-12-asset-extract.md`：

**英文**：`Location: [地点]. Time: [时间]. Atmosphere: [氛围]. Lighting: [光线描述]. Effects: [环境特效]. Details: [关键细节].`

**中文**：`地点：[地点]。时间：[时间]。氛围：[氛围]。光线：[光线]。特效：[特效]。细节：[细节]。`

### 提示词结构（英文版）

```
[MOST IMPORTANT — SCENE APPEARANCE]
{{scene_prompt}}

[Task]
场景四象限模块化视觉拆解板，纯白背景，细灰分割线

[Composition — 四象限 2×2]
左上：全景建立镜头
右上：线稿结构图 + 4-5色卡
左下：近景细节特写（材质纹理）
右下：三个垂直堆叠模块（光线方向、空间层次、材质属性）

[Style] {{style_prompt}}, {{era}}
[Lighting] 四象限统一光源方向
[Quality] 绝对禁止出现人物。纯白背景。无文字标签。
```

### 特殊处理

代码层强制注入前缀（`imageGenerator.ts:238-239`）：
```
CRITICAL: This is a PURE ENVIRONMENT image. ABSOLUTELY NO people, characters, humans, figures, silhouettes, animals, or any living creatures anywhere. Empty architecture/interior/landscape only.
```

## 三、故事板生成

**文件**：`src/main/data/prompt-templates/v1-07-grid-storyboard.md`
**DB ID**：`official-v1-grid-storyboard`
**用法**：`grid_storyboard`

### 七段式结构

```
Section 1 — 角色参考图 @url + 参考图优先指令 (权重 1.3)
Section 2 — 场景参考图 @url + 参考图优先指令 (权重 1.25)
Section 3 — 3×3 九宫格格式 + 画风关键词 (权重 1.3)
Section 4 — 场景空间锚点（地点/时间/天气/光源/特效/色调渐变）
Section 5 — 角色锚点 + 服装 + 武器 + 多人站位 (权重 1.3×2)
Section 6 — 9 镜分镜正文（11 列表格格式）
Section 7 — 全局一致性强制 (权重 1.25)
NEGATIVE — 负向提示词
QUALITY — 品质关键词
```

### 模板变量

| 变量 | 代码来源 | DB 字段 |
|------|---------|---------|
| `{{char_refs}}` | `charRefsText` — 每个角色 `@url` + 参考图优先指令 | `character_images.source_url` |
| `{{scene_ref_url}}` | `sceneRefUrl` | `scene_images.source_url` |
| `{{style_prompt}}` | `getStylePrompt()` | `project.style_prompt` + `style_name` |
| `{{scene_location}}` | `sceneDescText`（去 `Location:` 前缀） | `scenes.description` |
| `{{scene_time_weather}}` | `scenes.time_weather` 或 `project.era` | 两个表 |
| `{{scene_atmosphere}}` | `shots.lighting_mood` | `shots` |
| `{{scene_lighting}}` | 同上 | `shots` |
| `{{scene_effects}}` | `scenes.environment_effects`，兜底 `none` | `scenes` |
| `{{scene_reference_objects}}` | `scenes.reference_objects`，兜底 `none` | `scenes` |
| `{{char_role}}` | 所有角色 `description` 拼接 | `characters` |
| `{{char_outfits}}` | `parseDescField(desc, 'Outfit')` | 从 `characters.description` 解析 |
| `{{char_props}}` | `parseDescField(desc, 'Key prop')` | 同上 |
| `{{multi_character_positioning}}` | 帧-角色分配文本 | 代码计算 |
| `{{prop_name}}` | 写死 `'none'` | — |
| `{{prop_initial}}` | 写死 `'none'` | — |
| `{{shots_body}}` | 9 镜表格（代码动态构建） | `shots` 表 11 字段 |

### 权重分布

| 权重 | 位置 | 约束对象 |
|------|------|---------|
| 1.3 | Section 1 | 角色外观一致性 |
| 1.3 | Section 3 | 九宫格格式 |
| 1.3 | Section 5 | 服装一致性 |
| 1.3 | Section 5 | 武器/道具一致性 |
| 1.25 | Section 2 | 场景一致性 |
| 1.25 | Section 7 | 全局视觉一致性 |

### 角色参考文字

代码动态构建（`imageGenerator.ts`），每个角色一行：
```
[A] 角色名: @source_url (This reference image defines the EXACT appearance — facial features, face shape, hairstyle, outfit, body type. Use it as the sole visual source. Do NOT combine with text descriptions. Keep 100% consistent across all frames.)
```

多人时追加帧分配：
```
CRITICAL: 3 characters present. Frames 2,3,4,7,8,9 use 安敬思; Frames 5,6,7,8,9 use 李克用; Frames 9 use 李存孝.
```

### 分镜正文格式

```
[CHARACTER APPEARANCE LOCKED — Each character wears the EXACT same outfit...]

1｜2.4s｜EWS｜平视｜static｜24mm｜...｜deep focus｜...｜Wind howling｜建置时空
2｜1.9s｜WS｜俯拍｜pan｜35mm｜...｜...｜...｜...｜...
...
9｜1.4s｜MS｜平视｜static｜50mm｜...｜...｜...｜...｜关键转折
```

### API 调用

| 参数 | 值 |
|------|-----|
| 调用函数 | `generateGridStoryboard()` |
| 模型 | `lk888:gpt-image-2` |
| 参考图 | 最多 7 张（所有角色 + 场景） |
| 重试 | `withRetry()` 最多 2 次，追加 `fixSnippet` |
| 后处理 | sharp + SVG 叠印每格标注 |

## 四、内容安全过滤（三模板通用）

**位置**：`imageGenerator.ts` `sanitizePromptContent()`

**作用**：prompt 发送前替换敏感词，防止 API 内容审查拒绝

**覆盖范围**：

| 类别 | 示例 |
|------|------|
| 暴力/血腥 | blood → dark crimson, slaughter → defeat |
| 奴隶/束缚 | slave → captive, chains → cords, bound → held |
| 武器/战斗 | weapon → tool, sword → blade, battlefield → field |
| 中文敏感词 | 奴隶→奴仆, 血腥→暗红, 尸体→遗骸, 枯骨→碎石, 屠杀→战斗, 斩首→击败 |

**失败处理**：每次生成前自动 dump prompt 到项目目录 `storyboard_prompt_debug.txt` 供排查。
