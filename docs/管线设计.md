# 无限创意 (Wuxianchuangyi) 管线设计

## 架构总览

```
剧本输入
  │
  ├─→ [1] 剧本解析 (LLM) ──→ 章节 + 分镜 (每章6-9镜)
  │         │
  ├─→ [2] 资产提取 (LLM) ──→ 角色 / 场景 / 道具
  │         │
  ├─→ [3] 年代检测 (LLM) ──→ 年代标签
  │
  ├─→ [4] 角色生图 (API) ──→ 角色定妆照
  ├─→ [5] 场景生图 (API) ──→ 场景参考图
  ├─→ [6] 道具生图 (API) ──→ 道具参考图
  │
  ├─→ [7] 九宫格故事板 (API) ──→ 每章一张九宫格图 (含标注叠加)
  │
  └─→ [8] 视频生成 (API) ──→ 分镜视频
```

## 供应商路由

| 用途 | 模型 | 供应商 |
|------|------|--------|
| 语言模型 | `deepseek:deepseek-chat` | deepseek (DashScope) |
| 角色生图 | `lk888:gpt-image-2` | 无边界AI |
| 场景生图 | `lk888:gpt-image-2` | 无边界AI |
| 道具生图 | `lk888:gpt-image-2` | 无边界AI |
| 故事板 | `lk888:gpt-image-2` | 无边界AI |
| 视频 | `lk888:kwvideo-v2-ref` | 无边界AI |

## 管线详解

---

### 管线1：剧本解析 (script_parse)

| 属性 | 值 |
|------|-----|
| 输入 | 剧本文本 |
| 模型 | LLM (deepseek-chat) |
| 模板 | `v0-01-script-parse.md` (SD2.0 导演级) |
| 输出 | `[{chapter_title, shots:[{shot_index, shot_scene, shot_description, shot_description_en, dialogue, inner_monologue, narration, shot_type, camera_movement, focal_length, focus_point, character_actions, lighting_mood, sound_hint, narrative_function, video_prompt, video_prompt_zh, ...}]}]` |

**SD2.0 导演规则**：
- 长剧本自动分段，每段6-9镜 = 一张九宫格故事板
- 三幕式叙事弧：建置→冲突发展→转折→高潮→收尾
- 景别配比：WS×2 + MS×3 + CU×2 + ECU×1 + 特殊×1
- 每镜11项元数据：景别｜时长｜焦距｜机位｜运镜｜灯光｜焦点｜动作｜声音｜叙事功能
- 内容安全过滤：尸体/血腥/暴力 → 环境暗示
- Temperature: 0 (确定性输出)

---

### 管线2：资产提取 (asset_extract)

| 属性 | 值 |
|------|-----|
| 输入 | 分镜列表 |
| 模型 | LLM (deepseek-chat) |
| 模板 | `v1-12-asset-extract.md` (SD2.0 结构化) |
| 输出 | `{characters: [{name, description, description_zh}], scenes: [...], props: [...]}` |

**SD2.0 提取标准**：
- 角色：8字段嵌入 description 文本 (身份/年龄/五官/发型/服装/道具/体型/特征)
- 场景：6字段嵌入 description 文本 (地点/时间/氛围/光线/特效/细节)；DB表仅 name/description/reference_image 3列，待补独立字段见字段映射表
- 角色名中文、描述英文（发API）、中文描述存DB
- 角色模糊匹配+自动创建

---

### 管线4：角色生图 (character_image)

| 属性 | 值 |
|------|-----|
| 输入 | 角色ID + 描述 |
| 模型 | gpt-image-2 |
| 模板 | `v1-04-character-image.md` (SD2.0 角色参考图) |
| 输出 | 角色定妆照 (4面板横排: 上半身1.6x + 全身正面1x + 45°侧面1x + 背面1x) |

**特性**：
- 东亚人种约束（角色类型=human时）
- 非人角色跳过人种约束
- 支持画面比例选择（标准/2K/4K）
- source_url 保存供后续参考图调用
- 异步轮询（无边界API: POST→poll每5s，超时10min）

---

### 管线7：九宫格故事板 (grid_storyboard)

| 属性 | 值 |
|------|-----|
| 输入 | 章节ID (含6-9个分镜) |
| 模型 | gpt-image-2 |
| 来源 | DB七段式模板 `v1-07-grid-storyboard.md` + 代码动态构建 shots_body |
| 输出 | 一张3×3九宫格图 |

**SD2.0 七段式 Prompt 架构**：
```
[第1位] Reference @角色source_url (character consistency:1.3)    ← 有URL才加
[第2位] Reference @场景source_url (scene consistency:1.25)        ← 有URL才加
[第3位] (masterpiece, 3x3 grid...:1.3) + 画风 + 8K/HDR
[第4位] 【SPATIAL ANCHOR】空间地点+时间天气+主光源+色调渐变规则
[第5位] 【CHARACTER ANCHOR】角色锚点+多人站位+道具状态链
[第6位] shots_body: 1｜2s｜WS｜eye-level｜dolly in｜35mm｜... 表格格式
[第7位] (strict visual consistency...:1.25)
NEGATIVE + QUALITY
```

**工作流程**：
```
章节(6-9镜) → 每镜占一格 → 加载七段式DB模板 → 注入参考图URL
  → 构建shots_body(SD2.0表格格式) → 组装七段prompt → API生图
  → 下载 → sharp+SVG叠印标注 → 更新全部镜头poster
  → 失败自动追加修正语句重试一次
```

**标注格式（每格底部）**：
```
┌──────────────────────────┐
│ 1 WS | 1-2s | 35mm | 平视│
│ 慢推 dolly | [Sound] 环境风声  │
│ [Scene] 建置时空·角色入场     │
└──────────────────────────┘
```

- 每章一张图，每格取真实镜头数据
- 标注文字由 sharp+SVG 矢量叠印，不经过生图模型

---

### 管线8：视频生成 (video)

| 属性 | 值 |
|------|-----|
| 输入 | 分镜ID + video_prompt + 角色/场景参考图(source_url) + 故事板图(poster_image_path) |
| 模型 | `lk888:kwvideo-v2-ref` (Kling Video V2) |
| 模板 | `v1-13-video-pixverse.md` (SD2.0 视频生成) |
| 输出 | 分镜视频 (.mp4) |

**工作流程**：
```
分镜数据 → 加载DB模板(usage=video_generation) → 填充变量 → API生视频
  → 异步轮询 → 下载mp4（无边界API直接返回标准格式）
  → 故事板 poster_image_path 自动作为参考图传入
```

**模板含**：
- [OK] 单镜标准版 (chinese/english) — 已启用
- [OK] poster_image_path 参考图 — 已启用
- [TODO] 九宫格转视频版 (grid_to_video) — 模板就绪，待代码调用
- [TODO] 分段生成版 (segmented_first/segmented_second) — 模板就绪，待代码调用

**特性**：
- source_url 参考图（最多7张）
- PixVerse专用提示词仅对含 `pixverse` 模型触发
- 自动字幕区域遮盖
- 画面比例/帧数/帧率可配置
- 异步轮询（无边界API）

## 并发控制

- 最大5个并发请求
- 异步轮询：每5s查询，单次60s超时，总超时10min
- Temperature: 0 (LLM确定性输出)

## 已知限制

- 七段式SD2.0 prompt架构（代码读DB模板组装）
- API层限制：ControlNet/OpenPose不可用
- 本地参考图不支持（API仅接受公网URL）
- 内容安全过滤 + 失败自动追加修正语句重试
